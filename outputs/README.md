# Outputs

This folder holds the pre-computed SHIELD and baseline splits for each benchmark, so they can be used directly for ML training without rerunning the data splitting scripts. New splits will be added here over time; if need to apply SHIELD for a new benchamrk, see the main [README](../README.md#requesting-a-split) for how to request it.

You may access pre-computed SHIELD and baseline splits for each benchmark through [ZENODO](https://zenodo.org/records/22701102).
