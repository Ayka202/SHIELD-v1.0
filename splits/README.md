# Splits

Reference splits used for comparison against SHIELD.

Currently included: DataSAIL splits for HIV, LP-PDBBind, Lipophilicity, QM8, QM9, and Tox21 were obtained from the original publicaiton (DataSAIL splits are available at [DataSAIL Addendum Splits - ZENODO](https://zenodo.org/records/17376012)). SHIELD's own reference splits, and DataSAIL splits for the remaining benchmarks, will be added here over time — see the root [README](../README.md#requesting-a-split) to request one sooner.
